## 1. Architecture

- lottery.js exposes window.LotteryFX.show(prizeType, payload, onClose)
- lottery.css provides 6 distinct CSS3-only animation schemes
- index.html links both and calls LotteryFX.show from showPrize() tail
- prizeMask DOM preserved (non-destructive); original sheet still shows

## 4. Performance & a11y

- isLowEnd(): navigator.connection.effectiveType slow-2g/2g OR hardwareConcurrency<=2 -> reduce particles to 0.4x
- prefers-reduced-motion: reduce -> animations end immediately
- All particles use transform/opacity only - no reflow
- 720P>=50fps: needs on-device test (this machine has no 720P device)
