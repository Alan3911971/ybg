# 隐私与合规说明（宜必购盲盒系统）

> 适用：顾客 H5 / 商家后台 / 平台后台。编制 2026-08-17。

## 1. 数据收集与用途

| 数据类型 | 收集场景 | 用途 |
|---|---|---|
| 手机号（user_phone） | 顾客注册/登录/抽奖/下单 | 唯一身份标识、抽奖发放、余额/券归属、消息触达 |
| 商家账号/门店信息 | 商家开通 | 商家后台登录、门店配置、对账 |
| 消费金额/优惠/抵扣记录 | 下单/退款 | 业务记账、余额计算、跨店返还、审计对账 |
| 操作日志（audit_log） | 商家人工操作/平台调整 | 审计追溯、违规撤销 |
| 收款码图片 | 商家上传（模式A） | 页面展示收款（平台不接触资金） |

## 2. 数据留存与清理

| 数据 | 保留期 | 清理方式 |
|---|---|---|
| 余额流水 user_balance_flow | **永久**（业务资产台账，禁止物理删除） | 触发器保护 |
| 订单 / 优惠券 / 账户 | 永久（业务数据） | 不清理 |
| 审计日志 audit_log | 180 天 | 定时清理（每日 3:20） |
| 商家/用户站内消息 | 90 天 | 定时清理 |
| 播报事件 announce_log | 30 天 | 定时清理 |
| 动态核销码 | 2 分钟 | 过期即弃 |
| 登录会话 | 24 小时 | 过期清理 |

## 3. 安全措施

- 顾客短信验证码登录（归属验证）；商家/平台 token 会话（24h）
- 敏感配置（微信支付密钥等）AES-GCM 加密存储；平台展示脱敏
- 流水禁删、审计可撤销、负余额仅退款回滚允许
- 平台不配置/不管理商家任何支付密钥，不接触消费资金链路

## 4. 资金链路说明（合规要点）

- **顾客消费**：资金直接进入商家账户（模式A 商家收款码 / 模式B 商家扫码收款）；平台仅记账不碰资金
- **商家年费**：平台自身微信支付（商户资质由平台持有），密钥仅平台后台可见

## 5. 用户权利

- 用户凭手机号可查询本人全部资产与流水（钱包 H5）
- 平台保留基于审计日志的争议处理能力（撤销违规操作）
- 咨询/投诉：联系商家门店或软件公司平台
