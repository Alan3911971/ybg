# 生产 JAR 更新手册（登录 500 修复）

> 问题：生产 ybgtc.com 登录接口返回 500（merchant/admin 均如此），测试环境同版本返回优雅"账号或密码错误"
> 根因：生产部署的 jar 与测试环境不同版本（生产前端 md5=20aec918 ≠ 测试 ec75dddb）
> 目标：将生产 jar 更新为最新已验证版本，登录接口恢复优雅错误响应

## 操作步骤（宝塔服务器 / Docker Compose）

1. **获取最新 jar**（已验证，测试 12 套冒烟全绿）
   ```
   源：NAS /volume1/Download/ybg/deploy/ibigou.jar
   ```

2. **备份当前生产 jar**
   ```bash
   cd <生产 compose 目录>   # 含 docker-compose.yml 的目录
   cp ibigou.jar ibigou.jar.bak.$(date +%Y%m%d%H%M%S)
   ```

3. **替换 jar**
   ```bash
   cp /path/to/ibigou.jar ./ibigou.jar   # 上传后覆盖
   ```

4. **重启应用容器**
   ```bash
   docker compose restart app
   # 或：docker restart ibigou-app
   ```

5. **验证登录修复**
   ```bash
   # 应返回优雅错误（而非 500）：
   curl -X POST https://ybgtc.com/api/merchant/auth/login -d "account=probe&password=x"
   # 期望：{"code":-1,"msg":"账号或密码错误"}
   curl -X POST https://ybgtc.com/api/admin/auth/login -d "account=probe&password=x"
   # 期望：{"code":-1,"msg":"账号或密码错误"}
   ```

6. **验证核心服务**
   ```bash
   curl https://ybgtc.com/actuator/health        # {"status":"UP"}
   curl -o /dev/null -w "%{http_code}" https://ybgtc.com/h5/customer/index.html   # 200
   ```

## 验证基线（最新 jar 在测试环境已通过）

## 2026-08-19 P0 事故复盘：全 API 500（两重根因，均与 jar 无关）

### 现象
- 外网 https://ybgtc.com/api/** 全部 500（商家登录/钱包/配置/管理端）
- 本机 curl 127.0.0.1:8085 直连正常 → 疑点指向 nginx 层
- 响应头带 PHP 特征：content-disposition: inline;filename=f.txt、vary: Origin

### 根因① 生产 DB 缺列（flyway 禁用未迁移）
- 异常：Unknown column 'm1_0.balance_deduct_percent'
- 修复：按 NAS /volume1/Download/ybg/deploy/schema.sql 补齐 7 列
  balance_deduct_percent / daily_deduct_limit / receive_mode /
  receive_qr_img_alipay / receive_qr_img_wechat / receive_qr_img_merchant / receive_qr_status

### 根因② nginx rewrite 劫持 /api/* 到旧 PHP（关键）
- /www/server/panel/vhost/rewrite/ybgtc.com.conf 存在旧 PHP 规则：
  rewrite ^/api/(.+)$ /api.php?action=$1 last;
- 效果：所有 /api/* 请求被改写为 /api.php?... → PHP-FPM 处理 → 旧 PHP 业务错误 JSON 500
- **Java 服务从未收到请求，日志无任何异常**（干扰排查）
- 修复：注释 rewrite 行 + nginx -t + nginx -s reload（已备份 .bak.20260819_464）

### 预防（新 jar 上线核对清单）
1. 生产 DB 与测试库 schema 差异核对（flyway.enabled=false 时手工执行迁移脚本）
2. nginx rewrite 规则检查：grep -rn 'rewrite' /www/server/panel/vhost/rewrite/ybgtc.com.conf
3. 部署验证必须测**真实 API 路由**（用 unzip -p ibigou.jar | strings 提取 controller 路径，
   勿猜路径；C 端参数名是 userPhone 不是 phone）
4. 500 排查先看响应头是否 PHP 特征（content-disposition/vary: Origin）
