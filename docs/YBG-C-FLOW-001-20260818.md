## 需求（用户原话要点）
- "模式都是一样先开盲盒"——四个渠道（本店/美团/饿了么/抖音）**统一先开盲盒**。
- 美团/饿了么/抖音：开盲盒后**输入第三方订单金额**；**用户钱已付过，不需要付款环节**。
- 四个模式都按**消费金额的百分比赠送返还余额**，下次来消费用（= 跨店返还 cross_store_return_percent，默认 5%，平台可配）。
- 手机号登录一次后记住，不重复填写。

## 统一流程（四渠道一致，渠道差异仅在下单分支）
1. 扫码进入 H5 → URL `?m=<merchantNo>` 自动识别商家 + 渠道（本店默认 / 美团=1 / 饿了么=2 / 抖音=3）
2. 填手机号 → 验证码登录（`POST /api/customer/auth/send-code` + `/auth/login`，token 存 localStorage）
3. **开盲盒**（开奖在前，金额输入在后）：
   - 本店：`POST /api/customer/draw/normal`（merchantNo, userPhone）
   - 美团/饿了么/抖音：`POST /api/customer/draw/group`（merchantNo, userPhone, channel, qrCodeUniqueKey）
4. **开奖后输入订单金额**：
   - **本店**：输入订单原价 → 展示算价明细（`POST /api/customer/offline/calc` 自动四重min抵扣）→ 展示商家收款码（模式A）→ 用户长按付款 → 回 H5 提交订单（`POST /api/customer/offline/order`）→ 闭环
   - **美团/饿了么/抖音**：输入团购订单金额（>0 校验）→ **无算价/无收款码/无付款** → 提交登记（`POST /api/customer/group/register`）→ 闭环（后端自动发赠送余额）
5. 闭环后展示：赠送余额 X 元（下次消费可用）+ 弹窗文案
   - 文案：`恭喜您，本次消费已获得返还余额 X 元，已计入您的账户，请前往余额明细查看。`
