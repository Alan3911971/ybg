# 宜必购盲盒系统知识图谱

> 最后更新：2026-09-07（Z盘损坏后重建，代码根目录迁移至 D:\workspace-java\ybg-master）

## 一、系统架构

```
浏览器/APP(WebView) ──HTTPS──> nginx(ybgtc.com) ──> Spring Boot(ibigou.jar:8085) ──> MySQL(ybgtc.com库)
                                     │
                                     └── /h5/** 静态页面直读磁盘（wallet.html等）
                                     └── /api/** 反向代理到Java服务
```

- 后端：Java Spring Boot（com.ibigou.blindbox），Maven打包
- 前端：原生HTML/JS（h5目录），无框架
- 数据库：MySQL，库名 ybgtc.com（带点号）
- 部署：宝塔面板 + nginx + systemd/nohup

## 二、核心模块

### 1. 用户/认证
- CustomerAuthService / MerchantAuthService / AdminAuthService
- 登录接口参数 userPhone（form-urlencoded）
- 拦截器：CustomerAuthInterceptor / MerchantAuthInterceptor / AdminAuthInterceptor

### 2. 盲盒抽奖（DrawService）
- 奖池：BoxPrizePool / BoxPublicPool / BoxGroupPrizePool / BoxGroupPoolConfig
- 概率控制：BoxPrizeLimitStat、DailyDeductQuota、LimitCycle/LimitScope
- 动态二维码：DynamicQrService / IdentityQrService

### 3. 商城订单（IbigouService）
- IbigouGoods / IbigouOrder
- 下单成功 → announceService.record() 创建商家播报事件
- 优惠券：CouponService / UserCoupon
- 余额：BalanceService / UserBalanceFlow / WalletService / MemberWallet

### 4. 线下订单（OfflineOrderService）
- confirmPaid 已含播报逻辑

### 5. 支付（微信V2 + 支付宝）
- WxPayService（V2：mch_id 1440071102，app_id wx05a588674344ed25，APIKey V2）
- AlipayService（app_id 2021002144664045）
- CustomerPayController（下单）/ PayNotifyController（回调）
- 配置存 sys_global_config：wx_pay_enabled、wx_pay_mch_id、wx_pay_app_id、wx_pay_api_key、alipay_enabled、alipay_app_id、customer_pay_mode

### 6. 语音播报（AnnounceService）
- 表 announce_log（announce_id/merchant_no/event_type/content/create_time）
- 商家端轮询：/api/merchant/announce/poll?afterId=xxx（X-Merchant-Token头）
- 前端：merchant/index.html 的 pollAnnounce / btSpeak
- TTS：/api/tts?lan=zh&text=xxx&spd=5&source=web（百度女声MP3）
- 待解决：APP WebView无声音（需Android壳原生TTS桥接）

### 7. 其他
- ChatService（聊天）、MessageService（消息）、ReportService（报表）、JobService（定时任务）
- ConfigCryptoService（配置加密）、AlertService（告警）、AuditLogService（审计）

## 三、H5页面结构

```
h5/customer/  ├─ index.html 抽盒（4tab：抽盒/商城/订单/我的）
              ├─ ibigou.html 商城（订单区已移除）
              ├─ order-detail.html 订单详情（独立页，深色渐变+卡片）
              ├─ my-orders.html 我的订单（独立页，统计栏+卡片，无退款按钮）
              ├─ wallet.html 我的（优惠券/余额）
              ├─ pay.html 支付页（顾客端播报已取消）
              └─ pay.js（speak/speakPay已注释）
h5/merchant/   └─ index.html 商家后台（蓝牙打印+语音播报测试）
h5/admin/      └─ index.html 平台后台（微信/支付宝配置+支付模式选择）
```
